# OI Rating GitHub Pages 镜像

归档指定内网应用并保存到约定本地目录；Tangyixiao 已确认公开 GitHub 仓库和 Pages 网站，并允许公开备份中的姓名和成绩。

保留原页面、数据接口响应和提供的 JSON 在本机 `archive/`，清单记录来源、大小和 SHA-256。只读取入口和页面明确引用的公开数据接口。以已提供的备份作为发布数据：53 位选手、108 场比赛。

部署采用原生 HTML/CSS/JavaScript，保留原有导入、比赛、排行、选手、分析、设置和 Rating 算法。GitHub Pages 只托管静态文件，启动从同目录 `data.json` 载入公开数据；编辑写入浏览器 localStorage，刷新页面保留修改；手动恢复公开数据前确认覆盖。去除不适用的管理口令和上传操作，状态明确说明保存范围。打开网页默认展示总榜。

不新增共享写入后端。公开数据更新方式是替换 `data.json` 并推送到仓库 `tangyixiao/oi-rating`。部署从 main 根目录构建，使用 `.nojekyll`。

验收：在仓库子路径载入 53/108 条记录；六个标签页和分析有效；本机编辑及 JSON 导出/导入正常；编辑后重载保留、手动恢复确认生效；不请求内网或进行网络写入。检查桌面和移动截图；部署后验证 HTTPS 返回与本机文件哈希、真实线上浏览器验收。
